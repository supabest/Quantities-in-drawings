# 地面工程量计算 — 工作流与算量规则

> **文档版本**: v1.1（新增 R11–R13：面积以**墙位置**为界非铺材填充小方块（修正少算）、无填充无标注区域可能非装修范围不计入、按图框图名/图号称呼图纸）
> **日期**: 2026-09-27
> **适用范围**: 精装修住宅「地面（楼地面）净面积 + 按材料分类工程量」的按图算量
> **实证载体**: 广州珠实金融城 227 户型样板房（建筑面积 227㎡，净地面 ≈183–188㎡）
> **方法论铁律**: **按图算量，BOQ 只作事后对账（held-out），绝不参与几何/面积计算**

---

## 0. 目的

把"地面面积怎么从图纸可靠地算出来、怎么归到房间和材料、怎么对账"这条链路，固化为**可复现的工作流 + 明确的算量规则**，使后续优化有基线可对照、有规则可迭代。

## 2. 核心算量规则（R1–R13，每条含依据 + 反例）

### R1 — 净面积必须用 shapely 布尔 union，不得多边形面积求和
- **依据**: 同层多块闭合区可能重叠/含孔，求和会重复计数。
- **做法**: `unary_union(polys).area`；带孔房间用 `Polygon(ext, holes)`。

### R2 — DXF `floor` 层只读模型空间**顶层**闭合多段线，禁止递归进 INSERT 块
- **依据**: 递归 `virtual_entities()` 会混入多份图纸拷贝 + 0.63㎡ 单块地砖 → union 被拖成假值（实测 85/89 假高）。
- **反例**: 递归进块 → floor union 得 85/89 无意义碎片。
- **做法**: `for e in doc.modelspace(): if e.dxftype()=='LWPOLYLINE' and e.dxf.layer=='floor' and e.closed`。
- ⚠️ **修正（见 R11）**: `floor` 层闭合多段线是**饰面/铺材边界（内缩于墙面）**，用它算房间面积会**系统性少算**；应以**墙的位置**为界。

### R3 — 图纸尺度标定：PDF 1:100(A3) → `PT2M = 25.4/72/1000*100 = 0.03528 m/pt`
- **依据**: 本轮用共有房间做相似变换反解 **s=1.007–1.017**，证实 1:100 假设成立（面积偏差 ≤3%）。
- **DXF**: mm 1:1，坐标 ÷1000 → m。

### R4 — 三法对比结论：**单一源各取所长，禁止跨源几何叠加**（见 R5）
| 法 | 来源 | 产出 | 判定 |
|---|---|---|---|
| **a** | DXF 结构墙层 polygonize | 8–60㎡ 房间面 = **0**，仅 36.6㎡ 夹缝碎面 | ❌ 失败（墙碎、门洞漏） |
| **b** | DXF `floor` 层闭合区（顶层） | 围合小房间 union ≈85–92㎡，±几% | ✅ 精确但缺开敞客厅 |
| **c** | PDF 铺装图 polygonize | 严格 125.8㎡(69%) / 放宽 ≥1㎡ **158㎡(86%)**，含开敞客厅 66 | ✅ 覆盖最全 |

### R5 — b↔c（乃至 p11↔p22）**几何配准是病态的，禁止 overlay**
- **依据（面积签名铁证）**: b 按**房间边界**拆分（`19.3/14.4/13.4/11.0…`），c 按**铺材贴片**拆分（`67.2/12.7/7.4/7.3/7.1…`，主卧 21.7 被材料缝拆成 3 块 ~7）。两者对地面拆分语义不同 → 房间↔房间无一一对应。
- **反例**: 平移投票 5/11、最小二乘 4/11、RANSAC **3/11 内点 + 假旋转 −107°**；并集从 173 虚涨到 180 而含入率反降 = 错位重复计数。
- **结论**: 需要"完整覆盖"时取 **c 单源**；需要"逐房间精确"时取 **b 单源**；不做几何并。

### R6 — PDF polygonize 配方（c 法）
- 取 `page.get_drawings()`，仅处理 `('l',Vec2,Vec2)` 与 `('re',Rect)` 项（`'qu'` 无 x0，跳过）。
- 顶点 snap `s=1.5pt` 后 `polygonize(unary_union(lines))`。
- **过滤判据用面的 bbox**：`min(w,h)≥0.9m` 且 `长宽比≤4.5`；**不要**用逐顶点最小边长过滤（snap 后短闭合边会全杀 → 0 区）。
- 面积 `= face.area * PT2M**2`；`buffer(0)` 修自交。

### R7 — 房间命名/净面积用 p11 标注，**不要 polygonize p11 反推**
- **依据**: p11 是家具布置图，polygonize 出 **5568 碎面**（家具/洁具/尺寸线），"最小包含面"抓错（卧室一 8.5 vs 标 10.8、过厅 12.3 vs 1.8）。
- **做法**: `get_text("words")` 取带坐标词；**面积 token 严格判据 = 数字紧邻 "s.m"**（去噪，如剔除"中控屏 10.4"）；再就近匹配房间名（匹配距 ≤13pt 可靠）。

### R8 — 材料归属走"材料表 → 使用部位（房间名）"
- 代号体系：`WD 木饰面/木地板`、`ST 石材/岩板`、`TL 瓷砖/岩板`、`PT 乳胶漆`、`WC 扪墙布`、`UP 扪皮/扪布`、`MT 金属`、`GL 玻璃`、`MR 镜`。
- 概要表描述里已内嵌房间（"木地板 主人卧室地面""扪墙布 客厅"）→ 直接建 房间→材料。

### R9 — BOQ 是 held-out 考卷，只在对账阶段读；**盲算返回 0 就给 0，不得回填 BOQ 值**
- **自证**: b 法封壳返回内部=0 时如实报 0，不拿 BOQ 客厅 93.21 遮丑。唯一允许的 BOQ 参与是"用房间名贴标签展示"（命名 ≠ 用面积推断）。

### R10 — 口径差异要**披露而非掩盖**
- **实证**: BOQ「客厅」93.21 ≈ 图纸 客厅/茶室65.6 + 餐厅16.3 + 玄关7.3 + 过厅1.8（≈91–94）→ BOQ 把餐厅/玄关/过厅**并入"客厅"项**。按图算量应给图纸口径（客厅 65.6），并列为审计发现。

### R11 — 面积以**墙的位置**为边界，禁止用铺材填充小方块/饰面内缩边界（关键修正）
- **依据**: 之前用 `floor` 层闭合线/铺材填充作边界，它们**内缩于墙面** → 面积少算。房间净面积应量到**墙面（墙的内表面）**。
- **可操作判据（已在 idx11 验证）**: PDF 线宽可分离墙体——**粗线 width≥~0.5 是墙**（idx11 仅占 3%），**width=0 的 71667 段是填充**（铺材小方块/图案），**不得当边界**。优先用 **平面砌筑图 idx21** 或 **平面布置图 idx11 的墙线** 围合房间。
- **反例**: 用 width=0 填充区/`floor` 饰面线围合 → 少算。

### R12 — 无填充且无标注的区域可能**非装修范围**，不计入
- **依据**: 管井/风井/强电井/弱电井/消防水管井/燃气表/热水器平台/电梯厅等虽被墙围合，但**无饰面填充、无房间名标注** → 不在精装范围。
- **做法**: 只纳入**有地面饰面（HATCH/铺材）或有房间名+面积标注**的区域；其余标为「非装修范围/结构面积」排除，勿计入净地面合计。

### R13 — 房间净面积基准优先取**平面布置图标注值**（其即墙基准净面积）
- **依据**: 建筑师在平面布置图标注的 "NN.N s.m." 就是**量到墙的净面积**（比我从饰面/填充反推更准），故 §4 以它为基准；几何法（R11 墙围合）用于**交叉校验**标注值。

## 3. 标准工作流（分阶段，可复现）

> ⚠️ 本工作流受 [`WORKING_DISCIPLINE.md`](WORKING_DISCIPLINE.md) 约束：**先出“空间×部位”分析表(含缺图反馈)→再出分阶段计划→两道确认门通过后才计算**。下方 Stage 0′/Stage 0 即纪律一/纪律二的落地。

```
Stage 0′ 【R0 强制前置】图纸盘点与分类 —— 先找齐再干活
  ├─ 读 `02.目录`(图框图纸目录表) + [`DRAWING_REGISTER.md`](DRAWING_REGISTER.md)，按图号(List/G/P/E/CD/FD/SD/DQ/GD)分类
  ├─ 对照 §7 「地面就绪清单」确认必查图纸全部定位: **P01平面布置图 + P11平面砌筑图 + P12地面铺装图 + 物料說明p1 + G-06~09做法表 + FD地面大样**
  └─ 缺项先补找(换文件名/格式/DXF布局/块内)，未盘全不得开算

Stage 0  准备与标定
  ├─ 确认比例(P0x 均 1:100 A3)→ PT2M；DXF mm→m(÷1000)
  └─ ⚠️ 用**图号+图名**称呼(图号≠PDF页序: P01=平面布置图/P11=平面砌筑图/P12=地面铺装图)

Stage 1  房间清单（命名 + 净面积）—— 取 P01 平面布置图标注【R7】
  ├─ P01 get_text("words") → 面积token(紧邻s.m) + 房间名
  ├─ 就近配对(距≤13pt) → {房间名: 净面积}
  └─ 去噪/去重 → 16 间房清单（基准 188.2㎡）

Stage 2  面积几何提取（各取所长）
  ├─ b: DXF floor 顶层闭合区 → 围合小房间精确值【R2,R1】
  └─ c: PDF P12 地面铺装图 polygonize → 开敞区(客厅) + 全铺覆盖【R6】
     （b、c 不 overlay【R5】）

Stage 3  材料归属 —— 取材料表【R8】
  └─ 房间名 → 地面材料代号 → 名称（概要未点名的标"待核"）

Stage 4  汇总（按材料分类工程量）
  └─ Σ 面积 by 材料：石材 / 木地板 / 瓷砖 / 待核

Stage 5  对账与审计（BOQ held-out）【R9,R10】
  ├─ 逐房间: 图算净面积 vs BOQ 找平层 m² → 偏差
  ├─ 整户: 图算合计 vs BOQ 183.14 → 覆盖率
  └─ 口径差异(如客厅) → 单列审计发现，不回填
```

## 5. 已知失效点（明确"不要做"）

1. ❌ 递归进 INSERT 块取 floor 闭合区（→ 假值，见 R2）。
2. ❌ 用 DXF 结构墙 polygonize / flood-fill 封壳求房间（墙碎、门洞漏，见 a）。
3. ❌ b∪c 跨源几何叠加求"完整覆盖"（拆分语义不同，病态，见 R5）。
4. ❌ polygonize p11 家具图反推房间多边形（5568 碎面，见 R7）。
5. ❌ 用逐顶点最小边长过滤 PDF 面（全杀，见 R6）。
6. ❌ 拿 BOQ 数值反推/回填几何（违反方法论铁律，见 R9）。
7. ⚠️ PDF `get_drawings` 的 `'qu'`(quad) 项无 `.x0`，需跳过。
8. ❌ **用铺材填充小方块 / `floor` 饰面内缩线当面积边界 → 系统性少算**（应以墙的位置为界，用粗线 width≥~0.5 分离墙，见 R11）。
9. ❌ 把无填充无标注的管井/电梯厅等当房间计入净地面积（可能非装修范围，见 R12）。

## 6. 待办与优化方向（后续基于此迭代）

- **B｜墙面/天花材料矩阵**: 从各立面页（p28+）按名称抽取 → 补"房间 ×（地面/墙面/天花）"完整矩阵。

- **产品化**: 把 Stage 1–5 封装为 `floor_takeoff(p11, p22, dxf, material_pdf)` → 输出清单 + 对账 + 审计发现。
- **泛化验证**: 在 415 板房等其他户型复跑，检验规则普适性。
- **回归测试**: 用 §4 基准值建 pytest 断言（净地面 188.2、客厅 65.6、石材 99.0…）。
- **🔴 优先修正（本轮提醒）**: 用**墙线（width≥~0.5 分离）/平面砌筑图 idx21** 重算房间净面积，对比并纠正之前用 `floor` 饰面线/铺材填充导致的**少算**；同时按 R12 剔除非装修范围区域。
