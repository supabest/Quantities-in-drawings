# 图纸分类清单（Drawing Register）— 算量前置强制盘点

> **版本**: v1.0　**日期**: 2026-09-27
> **地位**: **一切算量/识别任务的第 0 步产物**。动手前必须先读本表、确认对应图纸齐全，再开工。
> **来源**: `02.目录 rev-02.dxf` 图框「图纸目录」表（图号+图名+比例，权威），叠加全目录文件盘点与 PDF 图框核对。
> **教训锚点**: 曾因未先盘点图纸而漏找「物料表 PDF / 平面砌筑图 / 地面大样 FD / 做法表 G06-09」，把 PDF 页序 idx11/22 误当图号——**先分类，后干活**。

## 0. 图号命名规则（一眼判定图纸类型与算量用途）

| 前缀 | 含义 | 算量归属 |
|---|---|---|
| `List` | 目录 | — |
| `G-0x` | 统一说明；**G-06~09 = 空间材料做法表** | **做法/构造 → 材料归属** |
| `P0x` | **平面系统**（1:100） | 面积/几何主源 |
| `E-xx` | **立面图**（1:50，按房间） | **墙面/天花材料** |
| `CD-xx` | 天花通用大样 | 天花构造 |
| `FD-xx` | **地面通用大样** | **地面构造做法** |
| `SD-xx` | 墙身通用大样 | 墙面构造 |
| `DQxx` | 背景墙大样 | 墙面装饰 |
| `GDxx` | 固装（家具）大样 | 固装家具 |

> ⚠️ **图号 ≠ PDF 页序**：图纸编号「P11 = 平面砌筑图、P12 = 地面铺装图、P01 = 平面布置图」。称呼一律用**图号+图名**，禁用「pXX」这种页序简称。

## 6. 文件位置与格式

- `装修图纸/227户型/` — 原始 **DWG**（01–16 号图 + 物料表 PDF + 415 材料 xlsx）。
- `装修图纸/227户型dxf/` — **转换后 DXF**（同名 01–16）+ **施工图纸.pdf**（idx0–80，渲染整册）+ BOQ xlsx。
- `装修图纸/工控方案图/` — **另一项目**（20 层平面布置/材料说明），**与 227 无关，勿纳入**。
- 编号文件 ↔ 图号：05 平面图 = P01~P15 合集；06/07 立面 = E；08/08A 天花大样 = CD；09 = FD；10 = SD；11/11a = DQ；12–16 = GD。

## 7. 按算量对象的「图纸就绪清单」（checklist）

| 算量对象 | 必查图纸（齐全才算可开工） |
|---|---|
| **地面面积** | P01 平面布置图(净面积) + P11 平面砌筑图(墙界) + P12 地面铺装图(铺材) |
| **地面材料** | 物料說明 p1 + G-06~09 做法表 + FD 地面大样 + P12 |
| **墙面** | E-01~13 立面图 + SD 墙身大样 + DQ 背景大样 + 物料說明 |
| **天花** | P02~04 天花图 + CD 天花大样 + E 立面顶部 |
| **对账** | 227 BOQ xlsx（held-out，仅最后一步） |

> **规则 R0（前置）**：任一算量开工前，先对照本表把「必查图纸」全部定位到具体文件/PDF 页；缺项先补找（换文件名/格式/布局/DXF 块内），不得在未盘全的情况下开算。
