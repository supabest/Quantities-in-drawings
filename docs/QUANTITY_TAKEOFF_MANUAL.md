# 第一部分 · 作业纪律（Working Discipline）

> 最高优先级流程规范。凡图纸识别 / 工程量计算任务必须遵守；与之冲突的操作一律作废重来。

## 纪律一：先盘图，后动手
- 收到图纸后，**第一步不是计算**，而是**全面盘点并对图纸分类**。
- 必须先读**图纸目录**（如 `02.目录.dxf` 图框「图纸目录」表：图号 + 图名 + 比例），据此列全所有图纸并按类型归类，确认与本次任务对应的图纸是否齐全（见第二部分）。
- **不得等用户提醒才去找对应图纸**——找不到时要主动穷举（换文件名 / 格式 / DXF 布局 / 递归块内 / PDF 图框标题栏）。

## 纪律二：按图框认图，禁用页序简称
- 图纸以**图框「图纸名称」栏** + **右下角「图纸编号 / 图号」栏**为准来识别与称呼。
- **图号 ≠ PDF 页序**（例：P01=平面布置图、P11=平面砌筑图、P12=地面铺装图，与 PDF 渲染 idx 不是一回事）。沟通与产出中一律用**图号 + 图名**。

## 纪律三：三步作业流程（含两道确认门）
### 第一步 · 图纸详细分析与分类
- 按图号分类全部图纸；按 **空间 × 部位（地面 / 墙面 / 天花 / 机电 / 固装 …）** 列成**覆盖表**；
- **凡缺图必须在该表中注明并反馈用户**，缺图包括但不限于：某空间某部位无对应图纸；图纸正文**无法机读**（如做法表正文为 A3 另图 / 图片，文字层取不到）；命名对不上、范围存疑的区域。
- ➡️ 产出「图纸分析表（空间×部位 + 缺图反馈）」交用户确认。 ← **确认门 ①**
### 第二步 · 制定分阶段工作计划
- 明确先算什么、再算什么（如 地面 → 墙面 → 天花 → 机电 → 汇总）；每阶段列出：用哪些图纸、产出、依赖、对账点。
- ➡️ 产出「分阶段工作计划表」交用户确认。 ← **确认门 ②**
### 第三步 · 确认后进入计算
- **两道确认门未通过前，不得开始计算**；计算阶段遵守第三部分（及后续各部分）规则与纪律四。

## 纪律四：算量方法论铁律（贯穿始终）
- **按图算量**：面积/数量一律由**几何从图纸独立算出**，每行带几何计算式与追溯；
- **BOQ / 工程量清单不作数值来源、不作对账目标**，仅用于:①开发期交叉校验(结果偏差如实披露、不回填)、②提供**列项与计量单位(m²/m/个)模板**；**生产环境无 BOQ**，全靠几何管线自算；
- **不得用 BOQ 值反推/回填几何**；盲算返回多少就报多少，返回 0/异常如实披露；
- **口径差异要披露而非掩盖**（如几何=全墙基层 vs BOQ=局部饰面；净面积 vs 含墙）；
- 空间/部位归属优先用**墙的位置**为界，不用铺材填充等内缩边界（见第三部分 R11–R14）。

## 每轮开工前自检清单
- [ ] 已读图纸目录、盘全并分类图纸？（纪律一 / 第二部分）
- [ ] 全程用图号 + 图名称呼？（纪律二）
- [ ] 「空间 × 部位」分析表已出、缺图已标注并反馈？（确认门①）
- [ ] 分阶段工作计划已发、已获确认？（确认门②）
- [ ] 计算只用图纸、BOQ 仅作对账不回填、口径差异已披露？（纪律四）

## 3.2 核心算量规则（R1–R14，每条含依据 + 反例）

### R1 — 净面积必须用 shapely 布尔 union，不得多边形面积求和
- **依据**: 同层多块闭合区可能重叠/含孔，求和会重复计数。
- **做法**: `unary_union(polys).area`；带孔房间用 `Polygon(ext, holes)`。

### R2 — DXF `floor` 层只读模型空间顶层闭合多段线，禁止递归进 INSERT 块
- **依据/反例**: 递归 `virtual_entities()` 混入多份图纸拷贝 + 0.63㎡ 单块地砖 → union 被拖成假值（实测 85/89 假高）。
- **做法**: `for e in doc.modelspace(): if e.dxftype()=='LWPOLYLINE' and e.dxf.layer=='floor' and e.closed`。
- ⚠️ `floor` 层闭合线是**饰面/铺材边界（内缩于墙面）**，用它算面积会**系统性少算**（见 R11）。

### R3 — 尺度标定：PDF 1:100(A3) → `PT2M = 25.4/72/1000*100 = 0.03528 m/pt`
- **依据**: 相似变换反解 **s=1.007–1.017**，证实 1:100（面积偏差 ≤3%）。DXF mm 1:1，坐标 ÷1000 → m。

### R4 — 三法对比：单一源各取所长，禁止跨源几何叠加（见 R5）
| 法 | 来源 | 产出 | 判定 |
|---|---|---|---|
| a | DXF 结构墙 polygonize | 8–60㎡ 房间面=**0**，仅 36.6㎡ 夹缝碎面 | ❌ 失败（墙碎、门洞漏） |
| b | DXF `floor` 闭合区(顶层) | 围合小房间 ≈85–92㎡ | ✅ 精确但缺开敞客厅 |
| c | P12 铺装图 polygonize | 严格 125.8(69%) / 放宽 ≥1㎡ **158(86%)**，含客厅 66 | ✅ 覆盖最全 |

### R5 — b↔c（乃至 P01↔P12）几何配准是病态的，禁止 overlay
- **依据（面积签名铁证）**: b 按**房间边界**拆（`19.3/14.4/13.4/11.0…`），c 按**铺材贴片**拆（`67.2/12.7/7.4/7.3/7.1…`，主卧 21.7 被材料缝拆成 3 块 ~7），拆分语义不同 → 房间↔房间无一一对应。
- **反例**: 平移投票 5/11、最小二乘 4/11、RANSAC **3/11 内点 + 假旋转 −107°**；并集从 173 虚涨到 180 而含入率反降。
- **结论**: 要"完整覆盖"取 **c 单源**；要"逐房间精确"取 **b 单源**；不做几何并。

### R6 — PDF polygonize 配方（c 法）
- 取 `page.get_drawings()`，仅处理 `('l',..)` 与 `('re',..)` 项（`'qu'` 无 x0 跳过）。
- 顶点 snap `s=1.5pt` 后 `polygonize(unary_union(lines))`。
- **过滤用面的 bbox**：`min(w,h)≥0.9m` 且 `长宽比≤4.5`；**不要**用逐顶点最小边长过滤（snap 后短边全杀→0 区）。
- 面积 `= face.area * PT2M**2`；`buffer(0)` 修自交。

### R7 — 房间命名/净面积用 P01 标注，不要 polygonize P01 反推
- **依据**: P01 是含家具的布置图，polygonize 出 **5568 碎面**，"最小包含面"抓错（卧室一 8.5 vs 标 10.8、过厅 12.3 vs 1.8）。
- **做法**: `get_text("words")` 取带坐标词；**面积 token 严格判据 = 数字紧邻 "s.m"**（去噪，如剔除"中控屏 10.4"）；就近匹配房间名（距 ≤13pt 可靠）。

### R8 — 材料归属走"材料表 → 使用部位（房间名）"
- 代号体系：`WD 木饰面/木地板`、`ST 石材/岩板`、`TL 瓷砖/岩板`、`PT 乳胶漆`、`WC 扪墙布`、`UP 扪皮/扪布`、`MT 金属`、`GL 玻璃`、`MR 镜`。
- 概要表描述内嵌房间（"木地板 主人卧室地面"）→ 直接建 房间→材料。

### R9 — BOQ 绝不参与数值/几何推断，仅作开发期校验与列项/单位模板
- **自证**: b 法封壳返回内部=0 时如实报 0, 不拿 BOQ 客厅 93.21 遮丑。唯一允许: 用房间名贴标签展示（命名 ≠ 用面积推断），以及用清单值做**事后交叉校验**(不算作目标)。

### R10 — 口径差异要披露而非掩盖
- **实证**: BOQ「客厅」93.21 ≈ 图纸 客厅/茶室65.6 + 餐厅16.3 + 玄关7.3 + 过厅1.8（≈91–94）→ BOQ 把餐厅/玄关/过厅并入"客厅"项。按图算量给图纸口径（客厅 65.6），列为审计发现。

### R11 — 面积以墙的位置为边界，禁止用铺材填充小方块/饰面内缩边界（关键修正）
- **依据**: `floor` 层闭合线/铺材填充内缩于墙面 → 面积少算；房间净面积应量到墙的内表面。
- **可操作判据（已在 P01 验证）**: PDF 线宽可分离墙体——**粗线 width≥~0.5 是墙**（仅占 3%），**width=0 的 71667 段是填充**，不得当边界。优先用 **P11 平面砌筑图** 或 **P01 墙线** 围合房间。
- 🔴 **边界约定（算哪个量认哪张图）**: **地面净面积、天花净面积→按 P11 砌筑墙线**（铺到墙根/封边，量到砌体内表面）；**墙面饰面板净面积→按 P01 完成面线**；砌筑墙芯结构建模→P11。P11 只画砌筑芯、**未画完成面线**；完成面线在 P01，**基层→完成面的附加层厚 = P01完成面线 与 P11砌筑面 间距实测**（或取做法表）。
- ⚠ **实测推翻“PDF 线宽→polygonize 围房间”（2026-09-28）**: P11/P01 取 w≥0.5 墙线 polygonize 仅得碎面（P11 最大 3.2㎡、合计 12.6㎡；P01 合计 16.2㎡）——**墙线不自闭合**（门洞断开+双线两片+墙跨多宽度），此路不通。**正解=DXF 图层法**：用 `05.227户型平面图…rev-33.dxf` 的 **`WALL` 层**（非拍平 PDF）。已核：**单位=mm**（INSUNITS=0/MEASUREMENT=1，按 1单位=1mm 尺寸才合理；切勿用 PDF 的 PT2M）；**模型空间叠多套平面副本**（须按空间分簇锁定单套）；`WALL` 层 795 段**不连通**（buffer1mm 得 78 碎片）。→ 围合需两步显式处理：**(a) 双线墙缓冲成实体墙带**（合并两片+取中心线供 3D）；**(b) 桥接门洞**（墙带并集自动补门垓）。尚未验证能否围出≈188.2。

### R12 — 无填充且无标注的区域可能非装修范围，不计入
- **依据**: 管井/风井/强弱电井/消防水管井/燃气表/热水器平台/电梯厅等虽被墙围合，但无饰面填充、无房间名标注 → 不在精装范围。

### R13 — 地面/天花净面积以 P11 墙线围合计算，BOQ 清单作开发期校验
- **依据**: 地面/天花净面积按 **P11 砌筑墙** 围合算得；对账基准 = **工程量清单楼面完成面积**（干区找平层 / 湿区石材地面+淋浴间 / 开放区客厅石材+玄关拼花），因其才是算量的真实目标。P01 标注面积已降为参考（实测为含墙/轴线口径，详见 R14 与 `docs/AREA_CALIBRATION_INVESTIGATION.md`）。

### R14 — 面积口径层级与对账判据（2026-10 定稿）
- **依据**: 调查证明 P01 标注面积(“NN.N s.m.”)并非净面积, 而是含墙/轴线口径; 各来源口径不统一导致“几何 vs 标注”系统偏差。
- **口径定义**:
  - **净面积(NetArea)**: 墙内面围合, 装饰面层算量用。`base_extract` 的 `r["area"]`。
  - **含墙外包(GrossArea)**: 房间四侧墙最外线定界, 作上界校验。`base_extract.gross_area()`。开放区(通铺无内墙)返回 None。
  - **BOQ 清单楼面完成面积**: 开发期交叉校验基准(**非数值来源**)。取清单各列“地面找平层”/“石材地面铺贴”/“客厅石材+玄关拼花”行。
  - **P01(p11) 标注面积**: 已降为纯参考, 可存于 IFC Pset_Room 的 `P11NetArea_m2` 字段但不作为对账判据。

- **实证**: 8/10 组“净~含墙”带内; 开放区几何净 90.41(通铺无定界→仍报净值, BOQ 106.61 仅披露供参考); 卧室二 含墙 12.84 vs BOQ 13.87 (~1㎡ 飘窗台, 属口径差, 不改几何值)。
- **详见**: `docs/AREA_CALIBRATION_INVESTIGATION.md`、`modeling/boq_ref.py`。

# 第四部分 · 墙面算量（Wall Takeoff）

> 实现：`modeling/wall_geometry.py`。产出 `outputs/model/wall_geometry.md`。

## 4.1 几何算法（唯一数值源）
- **每间净墙** = Σ(墙边长 × 净高) − Σ门洞口(宽×门高) − Σ窗洞口(宽×窗高)。
  - 墙边长：房间围合多边形各边（内墙面线），来自 05平面 rev-33 几何（`base_extract` poly，跳过 <100mm 碎边）。
  - 洞口宽：把 DOOR/WINDOW 线段**投影到墙边方向做“一维区间并集”去重**（修复多条平行窗线段直接累加→负墙面积的坑）；窗仅取平行边（剔垂直封口线）。
  - 高度：净高 3020 / 门 2100 / 窗 1500（**参数**，待立面/SD 精确）。
- **踢脚线**（m）= 净周长 − 门洞宽。

## 4.2 墙面口径真相（重要、勿误判）
- **几何全墙 = 整面内墙基层**（抹灰/腻子/涂料全数）；**BOQ“墙柱面”项 = 局部装饰面层**（硬包/瓷砖/石材背景墙子集）。**二者量的不是同一物，不可按总量对比判偏差**。
- 正确做法：**方向性校验** — 几何全墙 ≥ BOQ 饰面为合理（差异=饰面占比）；反向（几何<饰面）才是真异常（需查洞口过度扣减或贴砖高于净高假设）。227 实测：卧室/主卫饰面占比 88~93% 合理；**浴室一二三 105~115% → flag 待查**。

## 4.3 已验证基准值（回归锦点）
- 房间数 16；**毛 634.26 → 净 540.62 m²**（全内墙基层）；基层行合计 424.18 m²，踢脚线 148.14 m。

## 4.4 P2b 材料分区（实测可行性、2026-10）
- **命名可机读**（修正旧结论）：材料代号存于立面 `INSERT` **块属性**（tag=`FB-01`、值=`ST-03/WD-01/MT-01/UP-01/WC-01/GL-02/TL-01/PT-03`…）；06 读到 136 条、07 读到 126 条。（之前“ELE-TEXT 无文字→不可读”系只查 TEXT 层、漏了块属性。）
- **但分区无现成闭合面可积分**：`FIN` 层闭合线均为碎片（合计 3.5 m²，为踢脚/收边）；`ele-2`/`FIN`/`hatch` 的 HATCH 是**整面墙视图背景**（38/17/11 m²）非单材料区；136 代号仅 3 个落进墙级 HATCH。
- **DIM 网格估算也不可靠**（实测推翻）：单视图窗口内水平 DIM 约 20 段宽、垂直 DIM 50+ 段高，**密集且互相重叠**，无任何边界能把某个 FB 代号唯一对应到某个“宽段×带高”格 → 逐材料 m² 本质是猜，不自动。（立面坐标≈1:1 mm，净高 DIM≈3029≈3020。）
- **每幅↔房间标题不可读**：能解码的中文房间名只来自左侧一张小定位平面（P-TEXT，X≈-9000~10000 且重复两份），与立面视图 FB X（7767~246552）不对齐；立面视图无独立可机读房间标题。（中文解码本身可用 `base_extract._decode` / `textcodec.decode_acad_text`，只是图中无此信息。）
- **可靠可交付（P2b 可行边界）**：只能按立面**文件/粗 X 簇**输出“用到哪些材料代号 + 计数 + 材料名（经物料表 p1）”的材料清单/存在性；可附 `ele-2` 整面 HATCH 面积作该幅总墙面积锚点。**不臆造 房间×材料 的 m² 拆分**；如需真实分区面积，须补可机读的分区边界或人工。

## 4.5 洞口开模与模型交叉校验（P2c，2026-10）
- **洞口进模型**：`ifc_export` 现按**房间围合边（与 §4.1 算量同口径）**用 `wall_geometry.opening_intervals` 投影出门/窗逐樘区间，在宿主真墙上建 `IfcOpeningElement` + `IfcRelVoidsElement` 开洞。宽度=平面几何段长（可靠）；**高度用参数假设 门2100/窗1500、窗台高暂 0**。
- **宿主墙定位坑**：门洞正位于墙线**缺口处**，若按“到有限墙段垂距”会判不到宿主（垂距≈半门宽>容差）→ 改用**到墙无限直线垂距 + 沿墙投影重叠（放宽一个洞口长）**。227 实测：洞口 42 樘（门25/窗17），**35 樘成功开洞，7 樘孤儿**（垭口/外窗/非 strict 边界）。
- **交叉校验升级**（`wall_vs_ifc.py`）：从 IFC 回读 `IfcOpeningElement`（宽=矩形长边、高=挤出 Depth）清点洞口，新增“洞口清点”与“开洞覆盖”两行。模型唯一洞口面积 **87.81 m²** vs 算量每间扣（共享墙双计）**93.6 m²** → **口径差（双计）非错误**。
- **缺图待补（数据不可得）**：**门窗表不在本套装修图纸集**（大样 11/11a 明文“窗户详见建筑门窗表”→属建筑施工图）；平面无 M/C 编号标签。故洞口的**逐樘精确高度/窗台高/编号/防火等级/材质**无法自动获得，现为参数假设；要出门窗明细/构件身份，需向**建筑施工图索取门窗表**。

# 第五部分 · 天花算量（Ceiling Takeoff）

> 实现：`modeling/ceiling_takeoff.py`（复用 `floor_takeoff.decompose_mask`）。产出 `outputs/model/ceiling_takeoff.md`。

## 5.1 几何算法
- **天棚（刮腻子/涂料/吊顶平面）投影面积 = 房间围合净顶面积**（与楼面同一围合），单位 m²。comp_id 去重后按房间分组累加。
- 校验基准取 BOQ 天棚类的**最大单层**作顶面投影代理（同一顶面刮腻子/涂料/吊顶平面属重复工序，不可加总）。

## 5.2 口径与已验证值
- 几何=**净顶投影**（合理低于 BOQ，因 BOQ 含墙 + 造型吊顶**展开面积>投影**，与地面同规律）。
- 227 基准：分组几何天棚合计 **149.44 m²**（开放区 90.41、主卧+衣帽 17.15、主卫 7.54 …）。

## 5.3 P3b 造型吊顶展开面积（结案→部分推翻，VLM 识图复活新路线，2026-10-04）
- **需求**：造型吊顶展开面积（≠投影）需**闭合造型轮廓+剖面跌级轮廓**。
