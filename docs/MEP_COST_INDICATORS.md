# 机电单方造价指标库（D 层估算用）

> 机读版：`app/static/mep_cost_indicators.json`（v0.1 建议值，2026-10-06）。
> 用途：无机电专业图纸时，按【装修类型 × 机电专业】每㎡单方造价 + 管线长度单方系数出**估算账**。
> 口径纪律：D 层估算永久标注"单方指标·非图纸量"，与 A 层图上实测、B 层规则推算分账不混。

## 使用规则

1. 用户选装修类型 → 取该类型五专业推荐中值（mid）与区间（range）；
2. 估算造价 = Σ(单方中值 × 规模系数 scaleFactor) × 装修面积 S；区间按 range 低/高同法计算；
3. 管线长度估算 = 长度系数 × S（见 JSON meta.lengthCoefficients）；
4. S 取几何净装修面积（本项目=P3b 天花域 Σ=97.78㎡ 口径，披露来源）；
5. 指标为经验参考值，正式报价须按项目询价校准后替换 JSON。
