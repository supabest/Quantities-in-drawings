## 〇、定位与使用纪律（先读这一节）

本文件是**对照范本**，不是数据源。三条硬纪律：

1. **绝不向新项目供数**。新项目的每一个工程量必须由它自己的图纸几何推得（见
   `docs/QUANTITY_TAKEOFF_MANUAL.md` 与 [[boq-2]]），本范本只回答两个问题：
   *该不该有这一行？*（查漏）和 *这一行的量落在什么区间？*（查不合理）。
2. **只有无量纲指标可以当判据**。带 `m² / m / 个 / 元` 的绝对数值是 227 样本记录，
   用途仅限复算与追溯；可复用的是**比率、每 m² 套内强度、系数族、行项白名单**。
3. **凡本范本与你的图纸冲突，以图纸为准，并回来修订本范本**。样板房的造价形态差异极大
   （交付标 vs 展示标、是否含硬包/石材比例），单个样本只能给出"常见形态"而非"标准值"。

## 二、主要分部与行项总结（ZS02-A 主体册）

### 2.0 ⭐ 列项全集 = 94 行项区（本范本最高价值资产）

主体册行项区不是"227 做了哪些"，而是一套**完整的样板房精装修列项模板**：
每分部先把**所有可能的行项列空**，本项目不适用的留零量。三类分布：

| 类 | 行数 | 含义 | 范本用途 |
|---|---|---|---|
| 已计价（有合价） | 42 | 227 实际施工内容 | 单价梯度、工种配比、实物量强度判据 |
| 有量未计价 | 26 | 6 条 GRG 线条 + 20 条柜类/屏风（含 2 条带 `？`），合计 22 个 | 只做**存在性**查漏，不参与金额与 m² 校验 |
| 列了但零量 | 26 | 本项目不适用的标准行项 | **新项目查漏的第一清单** |

26 条零量行项（样板房常见做法全集，227 未采用）：

- 地面：地面基层 / 地面水泥砂浆找平层 / 地面瓷砖 / 地面石材
- 墙柱面：墙柱面油漆及裱糊 / 墙面刮腻子 / 墙面刮腻子每增减一遍 / 墙面 PT-01 有色乳胶漆 /
  墙柱面瓷砖 / 墙柱面石材 / 墙柱面装饰板 / 墙柱硬包饰面-卧室二 / 墙柱面踢脚线 /
  墙柱面装饰线 / 墙面木装饰线 100mm 宽以内(E07/B)
- 隔墙：隔墙及隔断 / 轻钢龙骨外隔墙 200mm 以内 / 轻钢龙骨内隔墙 100mm 以内 /
  轻钢龙骨内隔墙 200mm 以内 / 隔墙每增减一层基层板
- 天棚：天棚涂料 / 天棚吊顶 / 天棚灯槽·窗帘盒 / 天棚装饰线 / 天棚其他项目
- 其他：其他装饰

**读法与判据**：
1. 这 26 条正是"几何易算、清单易漏"的部分——**基层、找平、腻子、隔墙**四类。
   新项目算量若这四类一个都没有，几乎必然是识别遗漏而非真没做。
2. 227 的隔墙行项全零，因为它用**砌筑墙**（P11 砌筑图）而非轻钢龙骨隔墙。
   ⇒ 模板必须把"隔墙"作为**分部级必检项**，材料子类（砌筑 / 轻钢龙骨）按图纸判定，
   这与既有的间墙 100–250mm 平行判据（[[100-250mm]]）正好对齐：
   图上有间墙几何却没有隔墙行项 = 漏项。
3. `每增减一遍 / 每增减一层基层板` 这类**增减项行**是清单惯例：主项 + 增减项成对。
   算量输出若要与之对照，必须允许同一部位出现主项与增减项两行，不可按名称去重。

  售楼部/酒店会把木饰面与石材比例显著抬高。
- **单价梯度可用（元/m²，实体成本口径可靠）**：乳胶漆/背胶类 <30 → 瓷砖粘贴 128 →

- **⚠️ 墙地比判据的正确用法**：本册墙面 m² 合计 389.86 / 163.75 = **2.38**，

  227 = 296.76 / 437.22 = **0.68**，即样板房约 2/3 的净墙面有饰面。
  新项目若几何给出饰面/净墙 < 0.4，先怀疑饰面归属没做完。

### 3.2 取费公式（可直接落为应用参数）

来源：`ZS02-C` 与 `ZS02-A` 表头公式行，参数 AB5=0.17 / AC5=0.12。

```
管理费 F = (人工A + 机械E) × 17%
利润   G = (人工A + 机械E) × 12%
综合单价 H = A + B×C(主材单价×消耗量) + D(辅材) + E + F + G
税金   = 9%（装饰/门窗）；水电册同样按 9%
业态浮动：售楼部/样板间 = (人工+机械) × 0.20   ← 装修类型调整系数表
         户内精装 ≥3000 元/m² → ×0.20 ；2000~3000 → ×0.10 ；<2000 → ×0
```

水电册实际把"调整后人工单价"直接写成了 `A × 1.2`（如 62.93 → 75.52），正是上面 0.20 的落地。

> **⚠️ 本清单主体册的综合单价不可复用作单价库**，见 §6.1 公式缺陷。

## 六、已知缺陷与不采信项（照抄会出错的地方）

### 6.1 主体册管理费公式漏括号 → 综合单价虚高 31.4%

`ZS02-A` 第 23 列表头写"管理费"，公式为 `=(P12+V12*$AB$5)` 即 `A + E×17%`；
同列正确定义见 `ZS02-C` 表头 `F=(A+E)×17%`，且邻列利润写的是 `(P12+V12)*$AC$5`。
漏了括号 ⇒ 管理费被计成"整整一遍人工"。机械费 E≈0 的行（大多数）综合单价变成 `2A + D + 利润`。

实测：42 行合价按现有公式 171,874.14；按标准公式重算 **117,866.5 元，差 54,007.7 元（31.4%）**。
清单自身、`ZS02-T02` 汇总与税金全部沿用该值，所以账面自洽、看不出来。

**处置**：本范本**只采信 A/D/E 与主材消耗量系数**，不采信综合单价与合价的绝对水平；
所有百分比类判据改用实体成本口径（§4.2）或实物量口径（§4.3）。
这条同时提醒我们：应用侧套价公式必须由代码生成并单测覆盖，不能信任导入清单的公式串。

### 6.2 26 行"有量未计价"

6 条定制 GRG 线条（合计 163.93，**计量单位列为空**）+ 18 条柜类/屏风 + 2 条带问号行
（`不锈钢圆柱？`、`餐厅柜边层架？`），共 20 行、22 个：玄关柜、餐厅柜×2、茶室柜（左边立柜）、
茶室柜、电视柜、安全间柜、收纳间柜×2、主卧衣柜×2、主卧玻璃屏风、卧室一开放式衣柜、
卧室二衣柜、橱柜、浴室一/二/三浴室柜、主卫浴室柜。

⇒ **固定家具在样板房清单里是"按个列项、待大样图核 m² 价"的形态**，与既有裁定
（[[m]]: 个=排程量，几何不可靠，m² 待大样去噪）一致。
范本对应用的要求是：**这 20 个柜类行项进白名单做漏项检查（少一个柜就是漏），
但绝不参与金额与 m² 校验**。带 `？` 的行是设计师未确认项，应映射为 `待确认` 溯源 + 🔴 置信度。
GRG 线条行连单位都没有 ⇒ 导入任何清单前必须先做**单位完备性检查**，缺单位即报错不猜。

### 6.3 整册缺项（227 自身没做的，不能当范本的"应有形态"）

- 地面**找平层**、卫生间**防水层**、墙面**批腻子/底漆**：`ZS02-A` 里**行项已列出但工程量为 0**
  （见 §2.0 的 26 条零量行），防水层则整行都没有。
  → 恰是 `HIDDEN_ITEMS` 里的经验补全项。**结论：这三类在样板房清单里"该有"，
  但 227 把它们留空了——查漏判据要用 §2.0 的行项存在性，绝不能用 227 的零量当"不该有"。**
- `ZS02-C 拆除工程` 只有单价库、工程量列为空 → 本项目为新建，无拆除；不能据此认为拆改册可省。
- `ZS02-D 措施项目费` 只给 99/136/227 三个面积数字占位，未算合价。
- 木地板、售楼部 2F 汇总、99/136 户型等 sheet 属其他项目，不纳入样板房范本判据。

`14 工程数量 | 15 工种 | 16 人工单价 A | 17 主材名称 | 18 主材单价 B | 19 主材单位 |
