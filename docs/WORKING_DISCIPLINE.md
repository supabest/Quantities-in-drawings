# 算量作业纪律（Working Discipline）

> **地位**: 最高优先级流程规范。凡图纸识别 / 工程量计算任务，**必须**遵守本纪律；与本纪律冲突的操作一律作废重来。
> **版本**: v1.0　**日期**: 2026-09-27
> **配套**: 图纸清单见 [`DRAWING_REGISTER.md`](DRAWING_REGISTER.md)；各算量对象的算量规则见对应工作流文档（如 [`FLOOR_QUANTITY_WORKFLOW.md`](FLOOR_QUANTITY_WORKFLOW.md)）。

---

## 纪律一：先盘图，后动手
- 收到图纸后，**第一步不是计算**，而是**全面盘点并对图纸分类**。
- 必须先读**图纸目录**（如 `02.目录.dxf` 图框「图纸目录」表：图号 + 图名 + 比例），据此列全所有图纸并按类型归类，确认与本次任务对应的图纸是否齐全。
- **不得等用户提醒才去找对应图纸**——找不到时要主动穷举（换文件名 / 格式 / DXF 布局 / 递归块内 / PDF 图框标题栏）。

## 纪律二：按图框认图，禁用页序简称
- 图纸以**图框「图纸名称」栏** + **右下角「图纸编号 / 图号」栏**为准来识别与称呼。
- **图号 ≠ PDF 页序**（例：P01=平面布置图、P11=平面砌筑图、P12=地面铺装图，与 PDF 渲染 idx 不是一回事）。沟通与产出中一律用**图号 + 图名**。

## 纪律三：三步作业流程（含两道确认门）

### 第一步 · 图纸详细分析与分类
- 按图号分类全部图纸；
- 按 **空间 × 部位（地面 / 墙面 / 天花 / 机电 / 固装 …）** 列成**覆盖表**；
- **凡缺图必须在该表中注明并反馈用户**，缺图包括但不限于：
  - 某空间的某部位没有对应图纸；
  - 图纸正文**无法机读**（如做法表正文为 A3 另图 / 图片，文字层取不到）；
  - 命名对不上、范围存疑的区域。
- ➡️ **产出「图纸分析表（空间×部位 + 缺图反馈）」，交用户确认。** ← 确认门 ①

### 第二步 · 制定分阶段工作计划
- 明确**先算哪部分、再算哪部分**（如 地面 → 墙面 → 天花 → 机电 → 汇总）；
- 每阶段列出：用哪些图纸、产出什么、依赖、对账点；
- ➡️ **产出「分阶段工作计划表」，交用户确认。** ← 确认门 ②

### 第三步 · 确认后进入计算
- **两道确认门未通过前，不得开始计算。**
- 计算阶段遵守对应算量工作流文档的规则，以及纪律四的方法论。

## 纪律四：算量方法论铁律（贯穿始终）
- **按图算量**：面积/数量只从图纸（设计文件）推导；
- **BOQ / 工程量清单只作事后对账（held-out），绝不参与几何与算法推断**；盲算返回多少就报多少，不得用 BOQ 值回填遮丑；
- **口径差异要披露而非掩盖**（如图纸分间 vs BOQ 合并项）；
- 空间/部位归属优先用**墙的位置**为界，不用铺材填充等内缩边界（详见算量工作流 R11–R13）。

## 每轮开工前自检清单
- [ ] 已读图纸目录、盘全并分类图纸？（纪律一）
- [ ] 全程用图号 + 图名称呼？（纪律二）
- [ ] 「空间 × 部位」分析表已出、缺图已标注并反馈？（第一步 / 确认门①）
- [ ] 分阶段工作计划已发、已获确认？（第二步 / 确认门②）
- [ ] 计算只用图纸、BOQ 仅对账、口径差异已披露？（纪律四）
